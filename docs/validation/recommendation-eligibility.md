# Recommendation Eligibility

| Bucket | Count | Reason |
| --- | --- | --- |
| TOTAL | 510 | catalog works with editions |
| ELIGIBLE | 10 | published work + published edition + approved feature |
| INELIGIBLE | 500 | review status and/or missing approved feature |
| missing approved feature | 500 | feature review not complete |
| status issue | 500 | review records are intentionally excluded |

현재 500권은 수집 완료가 아니라 review queue다. 제품 관점의 추천 catalog는 10권이다.
