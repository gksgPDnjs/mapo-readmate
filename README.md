# ReadMate

AI와 대화하며 찾는 나만의 독서 성향

## 프로젝트 소개

ReadMate는 AI 독서 큐레이터와 카카오톡 형태의 대화를 통해 사용자의 독서 취향을 분석하고,
맞춤형 도서 추천과 독서 리포트를 제공하는 서비스입니다.

기존의 검색/장르 중심 추천과 달리, ReadMate는 대화 맥락을 반영해 질문을 이어가며
사용자의 목적과 상황까지 고려한 추천을 제공합니다.

## 기획 배경

- 많은 사용자가 "나에게 맞는 책"을 고르는 과정에서 어려움을 겪음
- 단순 장르/키워드 검색은 현재 상황과 독서 목적 반영이 부족함
- 초등학생/비독서층도 쉽게 사용할 수 있는 친숙한 체험형 서비스 필요

## 프로젝트 목표

- AI와 자연스럽게 대화하는 독서 큐레이터 구현
- 사용자 맞춤형 독서 성향 분석
- 성향 기반 맞춤 도서 추천(3권)
- 추천 이유 제공으로 신뢰성 강화
- 컨퍼런스 현장에서 2~3분 내 체험 가능한 흐름 구현

## 주요 기능

### 1) AI 독서 큐레이터 대화

- 카카오톡 형태 UI에서 AI가 먼저 질문 시작
- 사용자는 선택형 답변으로 대화를 진행
- 예시
	> 안녕하세요😊 오늘은 당신에게 딱 맞는 책을 찾아드릴게요! 먼저 하나만 물어볼게요. 책을 읽는 이유가 무엇인가요?

### 2) 맞춤형 질문 흐름

- 이전 답변을 반영한 후속 질문 제공
- 질문 예시
	- 책을 읽는 목적
	- 선호 분위기/장르
	- 독서 습관/분량
	- 선호 결말
	- 피하고 싶은 요소
- 예시
	> 아까 모험 이야기를 좋아한다고 했죠? 그렇다면 판타지와 현실 모험 중 어떤 이야기를 더 좋아하시나요?

### 3) 독서 성향 분석

- 대화 종료 후 성향 유형 분석
- 팀 기획 8가지 독서 성향 중 1개 결과 제공
- 추천 키워드(예: 모험, 성장, 상상력) 제공
- 예시
	> 🌱 호기심 탐험가형
	> 당신은 새로운 이야기를 경험하는 것을 좋아하며, 몰입감 있는 스토리와 성장형 이야기에 흥미를 느끼는 독자입니다.
	> 추천 키워드: #모험 #성장 #상상력

### 4) 맞춤형 도서 추천

- 성향 기반 도서 3권 추천
- 각 도서별 정보
	- 제목
	- 저자
	- 간단 소개
	- 추천 이유
- 예시
	> 아몬드 — 감정을 배우는 한 소년의 성장 이야기
	> 추천 이유: "성장형 이야기를 좋아하고 몰입감 있는 스토리를 선호하는 사용자의 독서 성향과 가장 잘 맞기 때문에 추천합니다."

### 5) AI 독서 리포트

- 최종 결과 화면 제공 항목
	- 독서 성향
	- 성향 설명
	- 추천 키워드
	- 추천 도서 및 추천 이유
	- 오늘의 독서 미션
- 예시
	> 오늘의 독서 미션: "추천받은 책의 첫 장을 읽고 가장 인상 깊었던 장면을 가족에게 이야기해보세요."

### 6) QR 저장 기능

- 결과 리포트를 QR로 저장/재확인 가능
- 컨퍼런스 방문객이 결과를 쉽게 가져갈 수 있도록 지원

## 서비스 흐름

1. 서비스 시작
2. AI 독서 큐레이터 인사
3. 카카오톡 형태 대화 진행
4. 사용자 답변 분석
5. 독서 성향 분석
6. 맞춤형 도서 추천
7. 추천 이유 제공
8. AI 독서 리포트 생성
9. QR 저장

## 화면 구성

- 화면 1: 시작 화면(인사 + 대화 시작 버튼)
- 화면 2: 대화 화면(AI 질문/사용자 선택 반복)
- 화면 3: 분석 로딩 화면
- 화면 4: 독서 성향 결과 화면
- 화면 5: 추천 도서 3권 + 추천 이유 화면
- 화면 6: AI 독서 리포트 + QR 화면

## 서비스 차별점

- 단순 설문이 아닌 대화형 취향 분석
- 친숙한 메신저 UX로 낮은 진입장벽
- 이전 답변을 반영한 맥락형 질문
- 단순 추천을 넘어 성향 분석 + 리포트 제공
- QR 저장으로 결과 재확인 가능
