# 저자·역자·기여자 관계 모델

## 결정

사람은 작품과 독립된 엔터티로 관리하고, 역할은 다대다 크레딧으로 표현한다. 번역자와 편집자는 판본마다 달라질 수 있으므로 작품 크레딧과 판본 크레딧을 분리한다.

## 테이블

| 테이블 | 핵심 열 | 제약 |
| --- | --- | --- |
| `catalog.contributors` | `id`, `display_name`, `normalized_name`, `sort_name`, `bio`, `language_code`, `merged_into_id` | `display_name`, `normalized_name` 필수 |
| `catalog.contributor_aliases` | `id`, `contributor_id`, `alias`, `normalized_alias`, `language_code` | `(contributor_id, normalized_alias)` 유니크 |
| `catalog.work_contributors` | `work_id`, `contributor_id`, `role_code`, `credit_order`, `credited_as` | 복합 PK, 순서 0 이상 |
| `catalog.edition_contributors` | `edition_id`, `contributor_id`, `role_code`, `credit_order`, `credited_as` | 복합 PK, 순서 0 이상 |

`role_code`는 `author`, `translator`, `illustrator`, `editor`, `adapter`, `narrator`, `compiler`, `other`만 허용한다. 원저자는 `work_contributors`, 번역자·낭독자 등 판본 특이 기여자는 `edition_contributors`에 저장한다.

## 병합·표시

- 동명이인은 자동 병합하지 않는다. 출처·생몰 정보 등 검토 근거가 있을 때만 `merged_into_id`를 설정한다.
- 표시 순서는 `credit_order`, `display_name` 순이다.
- 원본 표기에 필요한 이름은 `credited_as`로 보존하며, 검색은 정규화 이름과 별칭으로 수행한다.
