# 사서·기관 큐레이션 데이터 모델

## 테이블

| 테이블 | 핵심 열 | 제약 |
| --- | --- | --- |
| `curation.organizations` | `id`, `name`, `organization_type`, `website_url`, `verification_status` | 이름·웹사이트 중복 검토 |
| `curation.curators` | `id`, `organization_id`, `display_name`, `role_title`, `verification_status` | 개인식별 최소화 |
| `curation.curations` | `id`, `organization_id`, `curator_id`, `title`, `description`, `source_url`, `published_on`, `status` | 기관 또는 큐레이터 필수 |
| `curation.curation_items` | `curation_id`, `work_id`, `edition_id`, `ordinal`, `curator_note`, `source_record_id` | 복합 PK, 작품과 판본 중 하나 필수 |

## 정책

- `organization_type`: `public_library`, `school_library`, `national_institution`, `publisher`, `nonprofit`, `other`.
- 원 출처 링크와 수집 원본을 항상 연결한다.
- 추천 가중치에는 `verification_status = 'verified'`, `curations.status = 'published'` 항목만 반영한다.
- 큐레이션 목록은 수정 이력을 보존한다. 삭제된 원문은 `archived`로 표시하되 과거 추천 근거를 지우지 않는다.
