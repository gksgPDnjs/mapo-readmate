# 콘텐츠 주의사항(Content Note) 모델

## 원칙

내용 안내는 금지 또는 진단 수단이 아니라 사용자의 선택을 돕는 사실 정보다. 민감한 정체성이나 정신건강 상태를 추론하는 태그를 만들지 않는다.

## 테이블

| 테이블 | 핵심 열 | 제약 |
| --- | --- | --- |
| `catalog.content_note_types` | `code`, `label`, `description`, `severity_order`, `active` | `code` PK |
| `catalog.work_content_notes` | `work_id`, `note_code`, `intensity`, `scope`, `source_type`, `review_status`, `reviewed_at` | 복합 PK |
| `recommendation.content_boundaries` | `profile_snapshot_id`, `note_code`, `preference` | `preference`은 `avoid`, `deprioritize`, `no_preference` |

초기 `note_code`는 `death_or_grief`, `violence`, `school_bullying`, `war`, `family_conflict`, `discrimination`, `sexual_content`, `slow_pacing`, `complex_philosophy`로 제한한다. `intensity`는 `mentioned`, `some`, `frequent`, `central`이다.

## 필터 규칙

- `avoid`는 `some` 이상을 하드 필터하며, 사용자에게 제거 이유를 노출하지 않는다.
- `deprioritize`는 제외가 아니라 감점이다.
- 모든 공개 안내는 검수된 유형과 강도만 보여 준다. 근거가 불충분하면 `unknown`으로 두며 안전하다고 추정하지 않는다.
