# 작품(Work) / 판본(Edition) 데이터 모델

## 결정

`works`는 지적·서사적 작품, `editions`는 판매·대출 가능한 특정 출판물이다. 추천 중복은 작품 단위로 막고, 표지·ISBN·소장 여부는 판본 단위로 제공한다.

## 테이블

| 테이블 | 핵심 열 | 제약 |
| --- | --- | --- |
| `catalog.works` | `id`, `canonical_title`, `original_title`, `original_language_code`, `description`, `publication_status`, `merged_into_id` | `canonical_title` 필수, `merged_into_id`는 자기 참조 금지 |
| `catalog.editions` | `id`, `work_id`, `title`, `subtitle`, `isbn10`, `isbn13`, `publisher_name`, `published_on`, `page_count`, `format`, `language_code`, `cover_url`, `catalog_status` | `work_id` 필수, 페이지 수 양수, ISBN은 별도 정규화 정책 적용 |
| `catalog.edition_identifiers` | `id`, `edition_id`, `identifier_type`, `normalized_value`, `source_record_id` | `(identifier_type, normalized_value)` 유니크 |
| `catalog.work_relations` | `from_work_id`, `to_work_id`, `relation_type` | 복합 PK, 자기 참조 금지 |

## 상태와 인덱스

- `catalog_status`: `draft`, `review`, `published`, `suppressed`, `merged`.
- 추천 후보는 `works.merged_into_id is null`이며 `editions.catalog_status = 'published'`인 레코드로 한정한다.
- `editions(work_id, catalog_status)`, `editions(isbn13)`, `works(canonical_title)`에 인덱스를 둔다.
- 제목 검색은 `canonical_title`, `title`, `subtitle`의 정규화 텍스트에 trigram 인덱스를 둔다.

## 판본 선택 정책

동일 작품의 여러 판본 중 사용자의 언어·형식·접근성 조건을 만족하는 `published` 판본 하나를 선택한다. 동점이면 청소년 검수 판본, 최신 메타데이터, 실제 소장 가능 판본 순으로 우선한다. 선택 불가 시 작품 추천 자체를 숨긴다.
